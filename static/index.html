Giọng #1 luôn đọc tiêu đề mở đầu. Mỗi bình luận sẽ chọn ngẫu nhiên 1 giọng trong danh sách để tạo hội thoại sinh động.

Cơ chế phối giọng hàng loạt

  • Mở đầu cố định: Ảnh bài viết gốc ở đầu mỗi tập luôn được đọc bằng Voice ID 1.
  • Bình luận đa giọng: Mỗi bình luận lấy ngẫu nhiên một Voice ID trong danh sách bạn lưu.
  • Tiết kiệm Credit tối đa: Âm thanh đã tạo được lưu cache SHA-256 trên ổ cứng. Khi Render lại hoặc chia lại số tập, ứng dụng tái sử dụng ngay không gọi lại API.
  • Lưu ý quyền API Key: Nếu dùng Scoped API Key trên ElevenLabs, hãy bật quyền text_to_speech.
