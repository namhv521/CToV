# Visual system
Operate mode: Dark Desktop Studio (`100vh` locked desktop frame inspired by CapCut / DaVinci Resolve). Deep slate surfaces (`#0d1017`, `#121620`, `#171c29`), crisp soft-white typography (`BeVietnam`), studio blue primary action (`#4c7dff`), semantic emerald/amber/coral status badges, and `tabular-nums` counters for effortless monitoring during long unattended batch runs.

Navigation: 4 focused desktop workspaces — **Sản xuất hàng loạt** (Bulk Studio), **Kho video & Lịch sử** (Outputs & Crawl Archive), **Thư viện Media** (`Vid_nen`, `img_meme`, `mp3_meme` with pair diagnostics), and **Giọng đọc ElevenLabs** (API key + random multi-voice pool). Main Bulk Studio splits cleanly into a scrollable Left Configuration Deck (URLs input + `.txt` drag-drop + unified crawl/split/style preset + preflight bar + primary launch/append CTA) and a Right Live Monitor (4 KPI cards, live crawl/render progress bar, filterable URL queue, inline MP4 modal player, Explorer folder shortcuts, and 1-click retry/re-render).
